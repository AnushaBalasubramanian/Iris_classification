# 🌸 Iris Flower Classification - Task 1

This project is part of my machine learning journey, where I built a classification model using the popular **Iris dataset** and **Logistic Regression**.

---

## 📂 Dataset Overview

The Iris dataset contains 150 rows of flower measurements:
- Features:
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
- Target:
  - Species (Setosa, Versicolor, Virginica)

---

## ⚙️ What I Did

- 📥 Loaded the dataset using `pandas`
- 📊 Explored and preprocessed the data
- 🤖 Trained a **Logistic Regression** model using `scikit-learn`
- 🧪 Evaluated performance using:
  - Accuracy
  - Classification Report
  - Confusion Matrix

---

## 💡 Tools & Libraries

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

---


## 📈 Results

- Achieved good accuracy (~95%)
- Model can classify the flower species based on petal and sepal features
- Learned how to build a complete ML pipeline
